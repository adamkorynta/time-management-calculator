# Theme reference

Sampled from https://www.geiconsultants.com/ (computed styles) on 2026-10-22. Implemented in `src/index.css`
as Bootstrap 5 CSS-variable overrides.

| Token | Value | Use |
|---|---|---|
| Navy | `#003E53` | Body text, navbar, card headers, `--bs-primary` |
| Teal | `#007390` | Links, focus ring, outline buttons, `--bs-secondary` |
| Red | `#B0122A` | Danger / infeasible states |
| Gold | `#ECB83C` | Navbar accent rule, warnings |
| Cream | `#F7F5F1` | Page background |
| Fonts | Source Sans (400/600) body, Fjalla One headings | Loaded from Google Fonts (`Source Sans 3` is the current name of Source Sans Pro) |
| Favicon | `public/favicon-32.png`, `favicon-192.png`, `apple-touch-icon.png` | Downloaded from the site's `wp-content/uploads/2017/10/cropped-favicon-*.png` |

The GEI logo is intentionally not bundled; add the official asset if the app is to be branded further.
